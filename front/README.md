Фронтенд на React, TypeScript і Vite. Налаштування, змінні середовища, архітектура та сервіси бекенду описані в посібниках проєкту.

| Command / Команда | Purpose / Призначення |
| --- | --- |
| `npm ci` | Install dependencies / Встановити залежності |
| `npm run dev` | Start development server / Запустити сервер розробки |
| `npm run build` | Type-check and build / Перевірити типи та зібрати застосунок |
| `npm run preview` | Preview the build / Переглянути збірку |
| `npm run lint` | Run ESLint / Запустити ESLint |
| `npm run check:locales` | Compare EN/UK keys and placeholders / Порівняти ключі та змінні EN/UK |
